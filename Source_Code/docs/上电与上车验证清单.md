# 上电与上车验证清单

> 配合 `docs/PS2-诊断与修复方案.md` 使用。适用硬件：STM32F103C8T6 最小系统板 + 2S 18650 + 固定 5V 降压模块 + DRV8833 + PS2 无线接收器 + 四路 TT 马达麦轮底盘 + 3 路舵机。
> 当前已知坏件：**旧开发板（3.3V 轨劣化）已退役**，勿再上车。

## 1. 上电前的硬性检查（断电做）

| # | 检查项 | 判据 |
|---|---|---|
| 1 | 电池组电压 | 2S 满电 8.4V；<6.8V 先充电（低电量会放大一切小问题） |
| 2 | **电机电源独立** | 电池经粗线直供 DRV8833 的 VM；**不得从板载 5V/3.3V 取** |
| 3 | VM 就近电容 | 470–1000µF 电解 + 0.1µF 瓷片 |
| 4 | **舵机电源独立** | 舵机（尤其 MG995）用单独 5V（BEC/降压模块），**必须共地**；不能从板载 5V/3.3V 取 |
| 5 | 共地 | 电池负极、MCU GND、DRV8833 GND、接收器 GND、舵机电源 GND **单点汇聚** |
| 6 | 断电量 VCC 对 GND 电阻 | >100Ω（几十欧以下 = 短路） |
| 7 | 降压模块带载输出 | 板子运行时 **5.0V±2%**（低于 4.7V 必须换模块） |
| 8 | 板子 3.3V 脚 | **3.3V±3%**（低于 3.1V 说明 LDO 带载不足） |
| 9 | PS2 线束 | 两端拔空量两两之间电阻**全开路**，含弯折测试；连接器不得插偏一针 |
| 10 | PS2 接线核对 | DAT→**PB12**（输入上拉）、CMD→**PB13**、CS→**PB14**、CLK→**PB15**、VCC→**3.3V** |
| 11 | 驱动信号核对 | PA0/PA1=左前、PA2/PA3=左后、PB6/PB7=右前、PB8/PB9=右后（与 `motor.c` 映射一致） |
| 12 | 舵机信号核对 | 关节1→PA6、关节2→PA7、机械爪→PB0（与 `servo.h` 一致）；舵机信号线不要和电机线捆在一起走 |

## 3. 分步上电（每步都看灯 + 量 3.3V，异常立即停）

| 步骤 | 接什么 | 期望 |
|---|---|---|
| 1 | 只板子 + 降压 5V | 灯亮，3.3V≈3.3V，慢速档 LED（PA8）亮 |
| 2 | + 接收器 VCC/GND | 灯不变，接收器灯亮 |
| 3 | + 四根信号线 | 灯不变 |
| 4 | 烧固件（宏按第 2 节） | `g_ps2_dbg.init_ok==1`、`id==0x73` |
| 5 | + 驱动 8 根信号线 | 灯不变 |
| 6 | + VM / 电机 | 灯不变，电机静止（PWM 占空比 0） |
| 7 | + 舵机电源与信号（先只接一路） | 灯不变，舵机不动；按 L1/L2 才动 |

> 任何一步灯变暗：停下，先量该步新增那一路的电阻/电流，别继续加。
> 舵机那一步尤其要注意：**MG995 堵转电流可达 1A**，舵机电源塌了会连带把 5V 逻辑轨拉垮（共地但不同源时通常没事，务必确认）。

## 4. 台架自检（**必须架空车体**）

1. `MOTOR_SELFTEST_ENABLE=1`，烧录；
2. 上电后依次：**LF → LR → RF → RR**，每个轮子正转 1s、反转 1s（`g_motor_testing` = 当前轮子编号+1）；
3. 记录：
   - 是否只有对应的轮子转；
   - "正转"方向是否与预期一致 → 反的改 `USER/motor.c` 的 `MOTOR_SIGN_LF/LR/RF/RR` 为 `(-1)`；
4. 测完改回 `MOTOR_SELFTEST_ENABLE=0` 并重烧。

## 5. 遥控映射 v2（`control.h` + `led.c` + `servo.c`）与功能验证

**映射方案（2026-10-15 定案）**

| 输入 | 动作 | 实现 |
|---|---|---|
| △ / ✕ | **档位 +1 / -1**（慢→中→快，到顶到底不变；**上电默认中速**；边沿触发 + 250ms 去抖） | `gear_task()` |
| START | **制动**（真刹车，DRV8833 双输入同时拉满） | `Motor_BrakeAll()` |
| 方向键 上/下/左/右 | **70% 速度平移**（上下=前后，左右=左右平移；同按两个=斜向），受档位上限约束 | `vx/vy = ±CTRL_DPAD_SPEED` |
| 左摇杆 Y | 前后直行/后退，**推杆幅度在当前档位区间内线性映射** | `vx = lo + (hi-lo)·mag/1000` |
| 左摇杆 X | **原地自转**（绕底盘中心，纯旋转） | `vw += lx`（**受档位限制**，与平移一致） |
| 右摇杆 X | 绕**对侧**后轮水平旋转：推左 → 绕右后轮；推右 → 绕左后轮 | 几何补偿 vx/vy/vw（见下） |
| 右摇杆 Y | **已清空**（不产生指令） | — |
| L1 / L2 | 关节舵机 1（MG995，PA6/TIM3_CH1）增 / 减 | `Servo_Task()` |
| R1 / R2 | 关节舵机 2（SG90，PA7/TIM3_CH2）增 / 减 | 同上 |
| □ / ○ | 机械爪（MG90S，PB0/TIM3_CH3）张开 / 合拢 | 同上 |

**档位与动力区间**（全局占空比上限 `CTRL_DUTY_CAP = 92%`：实测更高占空比会导致**系统板复位甚至打火**，故留 8% 余量）

| 档位 | 区间 | 指示 LED | 满杆直行速度 |
|---|---|---|---|
| 0 慢速 | 10% ~ 30% | PA8 | 300 |
| 1 中速 | 30% ~ 60% | PA11 | 600 |
| 2 快速 | 60% ~ **92%** | PA12 | 920 |

**除制动外，所有正常底盘动作都受档位控制**：

| 动作 | 档位如何生效 |
|---|---|
| 左摇杆 Y 前后 / 方向键平移 | 直接用档位区间 `[lo, hi]`：300 / 600 / 920 |
| 左摇杆 X 原地自转 | 同平移，用档位上限 |
| 右摇杆 X 绕后轮 | 档位映射到**物理可用区间** 600 / 755 / 920（见下） |

> **为什么绕转不直接用档位的 300？** 绕后轮时四轮速度比值固定为 **2 : 1.08 : 0.92 : 0**（被绕的轮子恒为 0），
> 所以"次快轮"永远只有峰值轮的 **~54%**。TT 马达齿轮箱静摩擦约需 **≥30% 占空**才起转：
>
> | 峰值轮 | 次快轮 | 结果 |
> |---|---|---|
> | 300（慢速档原始上限） | ~160（16%） | **转不动 → 退化成"只有一个轮子转"**（实测遇到） |
> | 600 | ~324（32%） | 能转 ✅ |
> | 920（92% 上限） | ~495 | 能转 ✅ |
>
> 所以绕转的可用区间被物理限制在 600~920，档位把角速度映射到这段区间：
> **慢速 600 → 中速 755 → 快速 920**，档位依然控制绕转快慢（约 1.5 倍范围），且三档都转得动。
> 想更慢就调小 `CTRL_PIVOT_LIMIT_LO`（但低于 ~600 可能又转不动）。

**右摇杆 X（绕后轮）的几何依据**：绕点 `p` 转时车体中心速度 `v = ω × (C − P)`；本工程麦轮公式
（`LF=vx+vy+vw, RF=vx−vy−vw, LR=vx−vy+vw, RR=vx+vy−vw`）相当于标准式做了 `vy=−vy_std、vw=−ω_std`，于是
`vx = ω·p_y/arm`、`vy = ω·p_x/arm`、`vw = −ω`（`arm = 半轴距 + 半轮距`）。
取 `p = (−半轴距, ∓半轮距)`，此时被绕那个后轮的指令恰好为 0（主机端测试已验证）。

**舵机行程与机械爪（MG90S）**

| 通道 | 舵机 | 行程 | 说明 |
|---|---|---|---|
| CH1 (PA6) | MG995 | 500~2500µs = 0~180° | L1/L2 控制，上电回 0° |
| CH2 (PA7) | SG90 | 500~2500µs = 0~180° | R1/R2 控制，上电回 0° |
| CH3 (PB0) | MG90S | **500~1500µs = 0~90°** | **0°=完全闭合、90°=完全张开**；上电停 1000µs（45° 半开） |

> 机械爪两端都是**机械死点**：0°（全闭）和 90°（全开）都会顶住，**不要长时间停在两端**（会堵转发烫）。
> 夹持物体时舵机本来就处于近堵转状态，若夹住要长时间保持，建议把 `SERVO_GRIP_RELEASE_MS` 设为 1500（到位后持续按住超时自动断 PWM 失力），
> 或机械上做自锁/摩擦保持。角度接口：`Servo_SetAngle(2, 0/45/90)`。

**舵机行程校准（换舵机、改机构或出现卡住/发烫时做）**

> MG90S 是 180° **位置**舵机：500us=0°、1500us=90°、2500us=180°（见 `MG90S 舵机.md`）。
> **舵机自身能转 0~180°，不代表你的机构能用满**——机械爪机构只允许 90°。指令超出机构可用范围 = 顶在死点上持续堵转 = **卡住 + 嗡嗡响 + 发烫**。

1. `USER/servo.h` 里把 `SERVO_CALIBRATE_CH` 设为 `3`（机械爪通道）→ 烧录：该通道从 MIN 起**每 2 秒跳 50µs**，到 MAX 再折返；
2. 盯住它**从哪个脉宽开始卡住/发出堵转声** → 记下这两个值；
3. 把安全值（两端各留 20~50µs 余量）填回 `SERVO2_MIN_US` / `SERVO2_MAX_US`，`SERVO_CALIBRATE_CH` 改回 `0` 并重烧；

5. **再接上连杆**复测（区分"舵机问题"和"机构干涉"）。若脱开连杆正常、接上就卡 → 是机构死点/干涉，要改机械；
6. 如果接上后仍怕长时间堵转，把 `SERVO_GRIP_RELEASE_MS` 设为 `1500`：爪子到位后持续按住超过 1.5s 会**自动断开该通道 PWM 让舵机失力**（松开按键恢复）。

> 还有一种可能：**买到的是 360° 连续旋转版 MG90S**（外形一样、型号只差后缀）。
> 判别法：校准模式下给到某个脉宽后它**一直转不停、不会停在某个角度**，就是连续旋转版 → 无法做位置控制，必须换 180° 款。



> 失联保护已默认放宽到 **10s**：1s 会导致"稳住摇杆就停车、必须不停微动"（已实测遇到）。
> 想更硬的安全，建议用 START 键做使能式急停（还没实现，需要就告诉我）。

## 5b. 高占空比导致系统板复位/打火（实测遇到，必须处理）

现象：高档位大占空比时 MCU 复位、电机接插件打火。**已在固件侧把全局占空比上限压到 92%**（`CTRL_DUTY_CAP`），
但这只是缓解——复位/打火的根因在**电流路径**上，务必按下表逐项排查：

| # | 排查项 | 判据 / 处理 |
|---|---|---|
| 1 | 电机电源与逻辑电源是否分开 | 电机经粗线直供 DRV8833 VM；MCU 走独立 5V 降压。**不要共用细线** |
| 2 | VM 就近大电容 | DRV8833 的 VM-GND 之间 **470~1000µF 电解 + 0.1µF 瓷片**，线越短越好（缺它就是"瞬时掉压 → MCU 复位"） |
| 3 | 电池与线径 | 2S 满电 8.4V、内阻小的电池；电机线 ≥20AWG 并尽量短 |
| 4 | 接插件 | **打火多发生在接插件**：接触电阻大 → 局部发热/拉弧。换 XT30/XT60，压接可靠，别用杜邦线走电机电流 |
| 5 | 共地 | 电池负极、MCU GND、DRV8833 GND、接收器/舵机电源 GND **单点汇聚**（地线环路会引起复位） |
| 6 | 电池电量 | 电压低时同样功率下电流更大，更容易复位；<7.0V 先充电 |
| 7 | 堵转 | 轮子被卡住时电流最大，最容易复位；先架空车体测高档 |
| 8 | DRV8833 温度 | 发烫明显要散热或降低占空比上限 |

> 判据：如果**架空（空载）跑高档不复位、下地就复位**，基本就是第 1/2/3/4 条的电流路径问题。

### 5b-1. 判断"这次复位到底是什么原因"（`g_reset_cause`）

`main.c` 在启动最开头把 `RCC->CSR` 的复位标志锁存到全局变量 **`g_reset_cause`**，然后清除标志。
因为复位标志**只能软件清除**，不这样做的话第一次上电的 POR 标志会一直留着、后面任何复位都读不出真相。

**读法（CLion）**：Debug-STM32 启动调试 → Debug 窗口 **Variables 面板 → 点 "+" 添加 Watch：`g_reset_cause`**（或用 Evaluate Expression 输入）→ 让复位发生 → **Pause** → 看值。

| 位掩码 | 含义 | 说明 |
|---|---|---|
| **0x08000000** | PORRSTF | **上电/欠压类复位** → 供电确实被中断/塌陷（查电流路径、继电器、接插件） |
| **0x04000000** | PINRSTF | **NRST 复位脚被外部拉低** → 干扰/噪声/复位按键（查 EMI：电机端子电容、NRST 对地 100nF、走线远离） |
| 0x10000000 | SFTRSTF | 软件复位（代码主动复位，本工程不会出现） |
| 0x20000000 | IWDGRSTF | 独立看门狗（本工程未开） |
| 0x0C000000 | POR + PIN | **上电首次**的典型值（正常现象） |

> 判读：运行中复位后读到 **0x08000000** → 供电问题；读到 **0x04000000** → 复位脚被干扰（电源没问题）；
> 读到 **0x0C000000** → 断电式复位（既掉电又过复位脚）。
> 注意：上电后第一次启动读到 0x0C000000 是**正常**的，要判的是"运行中复位之后那次启动"读到的值。

## 7. 常见现象速查

| 现象 | 先查 |
|---|---|
| 灯变暗 / MCU 复位 | 5V 带载电压、3.3V 脚、电池电量、换板对比 |
| 推摇杆无反应 | `g_ps2_dbg.id`；`0x73` 才有摇杆数据；不再涨则查接线/供电 |
| 手柄突然不响应、按 ANALOG 才恢复 | 已自动修复：看 `mode_recover_count` 是否在涨；没涨说明未被识别为掉模式（查 `g_ps2_dbg.id`） |
| 前进变成打转 | 麦轮 `vx` 系数（应四轮同号） |
| 某个轮子反向 | `MOTOR_SIGN_xx` |
| 绕后轮时不是"一个轮子不动" | 量底盘尺寸填 `CTRL_HALF_LEN_MM`/`CTRL_HALF_WID_MM`；或调 `CTRL_PIVOT_OPPOSITE_SIDE`/`CTRL_PIVOT_SIGN` |
| 上电就窜车 | 摇杆是否在中位；`armed` 应先是 0；垃圾数据会解除使能 |
| 手柄关机后车继续跑 | 失联保护：`g_rc_dbg.stale` 是否变 1（超时 10s） |
| 舵机抖动/复位 | 舵机电源带载不够或没共地；单独 5V + 大电容 |
| 舵机不动 | 量 PA6/PA7/PB0 是否有 50Hz PWM（示波器/逻辑分析仪）；确认 `Servo_Init()` 被调用 |
