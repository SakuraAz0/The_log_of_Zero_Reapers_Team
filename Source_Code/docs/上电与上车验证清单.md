# 上电与上车验证清单

> 配合 `docs/PS2-诊断与修复方案.md` 使用。适用硬件：STM32F103C8T6 最小系统板 + 2S 18650 + 固定 5V 降压模块 + DRV8833 + PS2 无线接收器 + 四路 TT 马达麦轮底盘。
> 当前已知坏件：**旧开发板（3.3V 轨劣化）已退役**，勿再上车。

## 0. 上电前的硬性检查（断电做）

| # | 检查项 | 判据 |
|---|---|---|
| 1 | 电池组电压 | 2S 满电 8.4V；<6.8V 先充电（低电量会放大一切小问题） |
| 2 | **电机电源独立** | 电池经粗线直供 DRV8833 的 VM；**不得从板载 5V/3.3V 取** |
| 3 | VM 就近电容 | 470–1000µF 电解 + 0.1µF 瓷片 |
| 4 | 共地 | 电池负极、MCU GND、DRV8833 GND、接收器 GND **单点汇聚** |
| 5 | 断电量 VCC 对 GND 电阻 | >100Ω（几十欧以下 = 短路） |
| 6 | 降压模块带载输出 | 板子运行时 **5.0V±2%**（低于 4.7V 必须换模块） |
| 7 | 板子 3.3V 脚 | **3.3V±3%**（低于 3.1V 说明 LDO 带载不足） |
| 8 | PS2 线束 | 两端拔空量两两之间电阻**全开路**，含弯折测试；连接器不得插偏一针 |
| 9 | PS2 接线核对 | DAT→**PB12**（输入上拉）、CMD→**PB13**、CS→**PB14**、CLK→**PB15**、VCC→**3.3V** |
| 10 | 驱动信号核对 | PA0/PA1=左前、PA2/PA3=左后、PB6/PB7=右前、PB8/PB9=右后（与 `motor.c` 映射一致） |

## 1. 固件宏状态

| 宏 | 位置 | 正常行驶 | 台架自检 |
|---|---|---|---|
| `BRINGUP_HALT_LEVEL` | `Core/Inc/main.h:81` | **0** | 0 |
| `MOTOR_SELFTEST_ENABLE` | `USER/motor.h:16` | **0** | **1** |
| `PS2_ENABLE_RUMBLE` | `USER/ps2.h` | 1（默认） | 1 |
| `RC_STALE_TIMEOUT_MS` | `USER/rc.h` | 1000 | 1000 |
| `RC_STARTUP_ARM_MS` | `USER/rc.h` | 200 | 200 |

## 2. 分步上电（每步都看灯 + 量 3.3V，异常立即停）

| 步骤 | 接什么 | 期望 |
|---|---|---|
| 1 | 只板子 + 降压 5V | 灯亮，3.3V≈3.3V |
| 2 | + 接收器 VCC/GND | 灯不变，接收器灯亮 |
| 3 | + 四根信号线 | 灯不变 |
| 4 | 烧固件（宏按第 1 节） | `g_ps2_dbg.init_ok==1`、`id==0x73` |
| 5 | + 驱动 8 根信号线 | 灯不变 |
| 6 | + VM / 电机 | 灯不变，电机静止（PWM 占空比 0） |

> 任何一步灯变暗：停下，先量该步新增那一路的电阻/电流，别继续加。

## 3. 台架自检（**必须架空车体**）

1. `MOTOR_SELFTEST_ENABLE=1`，烧录；
2. 上电后依次：**LF → LR → RF → RR**，每个轮子正转 1s、反转 1s（`g_motor_testing` = 当前轮子编号+1）；
3. 记录：
   - 是否只有对应的轮子转；
   - "正转"方向是否与预期一致 → 反的改 `USER/motor.c` 的 `MOTOR_SIGN_LF/LR/RF/RR` 为 `(-1)`；
4. 测完改回 `MOTOR_SELFTEST_ENABLE=0` 并重烧。

## 4. 遥控映射（`USER/control.h`）与功能验证

**映射方案（2026-10-14 定案）**

| 输入 | 底盘动作 | 实现 |
|---|---|---|
| 左摇杆 前后 | 直行 / 后退，推杆距离 = 速度 | `vx` |
| 左摇杆 左右 | **原地自转**（`CTRL_LEFT_X_IS_ROTATE=0` 可改为左右平移） | `vw` |
| 左摇杆 斜推 | 两者合成（X 为自转时是"边走边转"，不是斜向平移） | — |
| 右摇杆 前后 | 前后各绕一侧轮组：推前 = 左轮组动、右轮组 0（绕右）；拉后 = 右轮组动、左轮组 0（绕左） | `vx = ry/2`、`vw = \|ry\|/2` |
| 右摇杆 左右 | 绕**尾部中点**为轴转（含横向平移补偿 `vy = vw·L/(lx+ly)`） | `vw = rx` |
| 方向键 上/下/左/右 | 按住以 **70%** 速度平移；同时按两个为斜向 | `vx/vy = ±700` |
| △ | 全速前进 | `vx = 1000` |
| ✕ | **真刹车**（DRV8833 双输入同时 100%，绕组短路制动） | `Motor_BrakeAll()` |

优先级：**✕ > △ > 方向键 > 摇杆**；摇杆之间可叠加。

**现场标定表（哪个方向反了就改对应宏，不用改逻辑）**

| 现象 | 改哪里 |
|---|---|
| 推前进却后退 | `control.h`：`CTRL_LY_SIGN` → `(-1)` |
| 左摇杆自转方向反 | `CTRL_LX_SIGN` → `(-1)` |
| 右摇杆前后绕的侧别反 | `CTRL_RY_SIGN` → `(-1)` |
| 右摇杆左右绕尾方向反 | `CTRL_RX_SIGN` → `(-1)` |
| 绕尾时轨迹有横移/漂移 | `CTRL_REAR_COMP_SIGN`，以及按实车尺寸改 `CTRL_HALF_LEN_MM` / `CTRL_HALF_WID_MM` / `CTRL_REAR_ARM_MM` |
| 想要左右平移而非自转 | `CTRL_LEFT_X_IS_ROTATE` → `0` |
| ✕ 刹车变滑行（或反之） | `motor.h`：`MOTOR_BRAKE_BOTH_HIGH` 取反 |

**验证步骤**

| # | 操作 | 期望 | 观测 |
|---|---|---|---|
| 1 | 上电后摇杆放中位 ≥200ms | 允许驱动 | `g_rc_dbg.armed==1` |
| 2 | 左摇杆推前 | 四轮同向 → 直线前进 | 反了改 `CTRL_LY_SIGN` |
| 3 | 左摇杆推左/右 | 原地自转 | 反了改 `CTRL_LX_SIGN` |
| 4 | 右摇杆推前 | 仅左轮组转（绕右侧） | 架空看哪些轮子转 |
| 5 | 右摇杆拉后 | 仅右轮组反转（绕左侧） | 同上 |
| 6 | 右摇杆推左/右 | 绕尾部中点转（车头画弧、尾端基本原地） | 轨迹不对调 `CTRL_REAR_COMP_*` |
| 7 | 方向键上（按住） | 70% 速度前进 | 上+左同按 → 斜向 |
| 8 | △ 按住 | 全速前进 | — |
| 9 | ✕ 按住 | 立即刹停（手推有阻力，不是滑行） | 若只是滑行 → 调 `MOTOR_BRAKE_BOTH_HIGH` |
| 10 | 拔手柄电池 / 按住摇杆完全不动 >10s | 停车 | `g_rc_dbg.stale==1`（超时已从 1s 放宽到 10s） |
| 11 | 手柄切绿灯(数字)模式 | 停车（不受控） | `g_ps2_dbg.id==0x41` |
| 12 | 运行中拔接收器 | 停车 + 自动重配置 | `reconfig_count` 增长 |

> 失联保护已默认放宽到 **10s**：1s 会导致"稳住摇杆就停车、必须不停微动"（已实测遇到）。
> 若要更硬的保护，用 START 键做使能式急停更合适（未实现，需要时告诉我）。


## 5. 观测变量速查（CLion 调试器 Watch）

| 变量 | 含义 |
|---|---|
| `g_ps2_dbg.raw[9]` | 最近一包原始字节 |
| `g_ps2_dbg.id` | `0x73`=模拟红灯、`0x41`=数字绿灯、其它=通信异常 |
| `g_ps2_dbg.init_ok` / `ok_count` / `fail_count` / `reconfig_count` | 初始化与通信质量 |
| `g_rc_dbg.armed` | 是否通过上电安全启动 |
| `g_rc_dbg.stale` / `unchanged_ms` / `protect_count` | 失联保护状态 |
| `g_rc_dbg.reject_count` | 垃圾数据/未回中次数 |
| `g_motor_testing` | 自检时当前轮子（仅在 `MOTOR_SELFTEST_ENABLE=1` 时存在） |

## 6. 常见现象速查

| 现象 | 先查 |
|---|---|
| 灯变暗 / MCU 复位 | 5V 带载电压、3.3V 脚、电池电量、换板对比 |
| 推摇杆无反应 | `g_ps2_dbg.id`；`0x73` 才有摇杆数据；不再涨则查接线/供电 |
| 前进变成打转 | 麦轮 `vx` 系数（应为四轮同号） |
| 某个轮子反向 | `MOTOR_SIGN_xx` |
| 平移/旋转方向反 | `MECANUM_STRAFE_SIGN` / `MECANUM_ROTATE_SIGN` |
| 上电就窜车 | 摇杆是否在中位；`RC_STARTUP_ARM_MS` 是否生效（`armed` 应先是 0） |
| 手柄关机后车继续跑 | 失联保护：`g_rc_dbg.stale` 是否变 1 |
