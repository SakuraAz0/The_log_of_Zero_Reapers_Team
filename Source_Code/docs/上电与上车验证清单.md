# 上电与上车验证清单

> 配合 `docs/PS2-诊断与修复方案.md` 使用。适用硬件：STM32F103C8T6 最小系统板 + 2S 18650 + 固定 5V 降压模块 + DRV8833 + PS2 无线接收器 + 四路 TT 马达麦轮底盘 + 3 路舵机。
> 当前已知坏件：**旧开发板（3.3V 轨劣化）已退役**，勿再上车。

## 1. 上电前的硬性检查（断电做）

| # | 检查项 | 判据 |
|---|---|---|
| 1 | 电池组电压 | 2S 满电 8.4V；<6.8V 先充电（低电量会放大一切小问题） |
| 2 | **电机电源独立** | 电池经粗线直供 DRV8833 的 VM；**不得从板载 5V/3.3V 取** |
| 2b | **DRV8833 的 STBY(nSLEEP) 必须接 VCC/高电平** | ⭐ 实测踩过：STBY 悬空 → 驱动输出被关断，PS2/LED/VM 全都正常但**电机完全不动**（看起来像"PA0 无 PWM"） |
| 3 | VM 就近电容 | 470–1000µF 电解 + 0.1µF 瓷片（**缺它 + STBY 接上后，一动摇杆就复位**） |
| 4 | **舵机电源独立** | 舵机（尤其 MG995）用单独 5V（BEC/降压模块），**必须共地**；不能从板载 5V/3.3V 取 |
| 5 | 共地 | 电池负极、MCU GND、DRV8833 GND、接收器 GND、舵机电源 GND **单点汇聚** |
| 6 | 断电量 VCC 对 GND 电阻 | >100Ω（几十欧以下 = 短路） |
| 7 | 降压模块带载输出 | 板子运行时 **5.0V±2%**（低于 4.7V 必须换模块） |
| 8 | 板子 3.3V 脚 | **3.3V±3%**（低于 3.1V 说明 LDO 带载不足） |
| 9 | PS2 线束 | 两端拔空量两两之间电阻**全开路**，含弯折测试；连接器不得插偏一针 |
| 10 | PS2 接线核对 | DAT→**PB12**（输入上拉）、CMD→**PB13**、CS→**PB14**、CLK→**PB15**、VCC→**3.3V** |
| 11 | 驱动信号核对 | PA0/PA1=左前、PA2/PA3=左后、PB6/PB7=右前、PB8/PB9=右后（与 `motor.c` 映射一致） |
| 12 | 舵机信号核对 | 关节1→PA6、关节2→PA7、机械爪→PB0（与 `servo.h` 一致）；舵机信号线不要和电机线捆在一起走 |

## 3. 分步上电（每步都看灯 + 量 3.3V，异常立即停）

| 步骤 | 接什么 | 期望 |
|---|---|---|
| 1 | 只板子 + 降压 5V | 灯亮，3.3V≈3.3V，慢速档 LED（PA8）亮 |
| 2 | + 接收器 VCC/GND | 灯不变，接收器灯亮 |
| 3 | + 四根信号线 | 灯不变 |
| 4 | 烧固件（宏按第 2 节） | `g_ps2_dbg.init_ok==1`、`id==0x73` |
| 5 | + 驱动 8 根信号线 | 灯不变 |
| 6 | + VM / 电机 | 灯不变，电机静止（PWM 占空比 0） |
| 7 | + 舵机电源与信号（先只接一路） | 灯不变，舵机不动；按 L1/L2 才动 |

> 任何一步灯变暗：停下，先量该步新增那一路的电阻/电流，别继续加。
> 舵机那一步尤其要注意：**MG995 堵转电流可达 1A**，舵机电源塌了会连带把 5V 逻辑轨拉垮（共地但不同源时通常没事，务必确认）。

## 4. 台架自检（**必须架空车体**）

1. `MOTOR_SELFTEST_ENABLE=1`，烧录；
2. 上电后依次：**LF → LR → RF → RR**，每个轮子正转 1s、反转 1s（`g_motor_testing` = 当前轮子编号+1）；
3. 记录：
   - 是否只有对应的轮子转；
   - "正转"方向是否与预期一致 → 反的改 `USER/motor.c` 的 `MOTOR_SIGN_LF/LR/RF/RR` 为 `(-1)`；
4. 测完改回 `MOTOR_SELFTEST_ENABLE=0` 并重烧。

## 5. 遥控映射 v2（`control.h` + `led.c` + `servo.c`）与功能验证

**映射方案（2026-10-15 定案）**

| 输入 | 动作 | 实现 |
|---|---|---|
| △ / ✕ | **档位 +1 / -1**（慢→中→快，到顶到底不变；**上电默认中速**；边沿触发 + 250ms 去抖） | `gear_task()` |
| START | **制动**（真刹车，DRV8833 双输入同时拉满） | `Motor_BrakeAll()` |
| 方向键 上/下/左/右 | **70% 速度平移**（上下=前后，左右=左右平移；同按两个=斜向），受档位上限约束 | `vx/vy = ±CTRL_DPAD_SPEED` |
| 左摇杆 Y | 前后直行/后退，**推杆幅度在当前档位区间内线性映射** | `vx = lo + (hi-lo)·mag/1000` |
| 左摇杆 X | **原地自转**（绕底盘中心，纯旋转） | `vw += lx`（**受档位限制**，与平移一致） |
| 右摇杆 X | 绕**对侧**后轮水平旋转：推左 → 绕右后轮；推右 → 绕左后轮 | 几何补偿 vx/vy/vw（见下） |
| 右摇杆 Y | **已清空**（不产生指令） | — |
| L1 / L2 | 关节舵机 1（MG995，PA6/TIM3_CH1）增 / 减 | `Servo_Task()` |
| R1 / R2 | 关节舵机 2（SG90，PA7/TIM3_CH2）增 / 减 | 同上 |
| □ / ○ | 机械爪（MG90S，PB0/TIM3_CH3）张开 / 合拢 | 同上 |

**档位与动力区间**（全局占空比上限 `CTRL_DUTY_CAP = 92%`：实测更高占空比会导致**系统板复位甚至打火**，故留 8% 余量）

| 档位 | 区间 | 指示 LED | 满杆直行速度 |
|---|---|---|---|
| 0 慢速 | 10% ~ 30% | PA8 | 300 |
| 1 中速 | 30% ~ 60% | PA11 | 600 |
| 2 快速 | 60% ~ **92%** | PA12 | 920 |

**除制动外，所有正常底盘动作都受档位控制**：

| 动作 | 档位如何生效 |
|---|---|
| 左摇杆 Y 前后 / 方向键平移 | 直接用档位区间 `[lo, hi]`：300 / 600 / 920 |
| 左摇杆 X 原地自转 | 同平移，用档位上限 |
| 右摇杆 X 绕后轮 | 档位映射到**物理可用区间** 600 / 755 / 920（见下） |

> **为什么绕转不直接用档位的 300？** 绕后轮时四轮速度比值固定为 **2 : 1.08 : 0.92 : 0**（被绕的轮子恒为 0），
> 所以"次快轮"永远只有峰值轮的 **~54%**。TT 马达齿轮箱静摩擦约需 **≥30% 占空**才起转：
>
> | 峰值轮 | 次快轮 | 结果 |
> |---|---|---|
> | 300（慢速档原始上限） | ~160（16%） | **转不动 → 退化成"只有一个轮子转"**（实测遇到） |
> | 600 | ~324（32%） | 能转 ✅ |
> | 920（92% 上限） | ~495 | 能转 ✅ |
>
> 所以绕转的可用区间被物理限制在 600~920，档位把角速度映射到这段区间：
> **慢速 600 → 中速 755 → 快速 920**，档位依然控制绕转快慢（约 1.5 倍范围），且三档都转得动。
> 想更慢就调小 `CTRL_PIVOT_LIMIT_LO`（但低于 ~600 可能又转不动）。

**右摇杆 X（绕后轮）的几何依据**：绕点 `p` 转时车体中心速度 `v = ω × (C − P)`；本工程麦轮公式
（`LF=vx+vy+vw, RF=vx−vy−vw, LR=vx−vy+vw, RR=vx+vy−vw`）相当于标准式做了 `vy=−vy_std、vw=−ω_std`，于是
`vx = ω·p_y/arm`、`vy = ω·p_x/arm`、`vw = −ω`（`arm = 半轴距 + 半轮距`）。
取 `p = (−半轴距, ∓半轮距)`，此时被绕那个后轮的指令恰好为 0（主机端测试已验证）。

**舵机行程与机械爪（MG90S）**

| 通道 | 舵机 | 行程 | 说明 |
|---|---|---|---|
| CH1 (PA6) | MG995 | 500~2500µs = 0~180° | L1/L2 按住增减、松开即停（点动），上电回 0° |
| CH2 (PA7) | SG90 | 500~2500µs = 0~180° | R1/R2 同上，上电回 0° |
| CH3 (PB0) | MG90S | **350~1350µs = 机构 0~90°** | **0°=完全闭合、90°=完全张开**；上电停在**完全张开** |

> **机械爪角度零点偏移（已校准 -13.5°）**：舵盘装在花键上（25 齿，一齿 14.4°），装偏会让整段行程偏移。
> 实测现象是"张开端顶死 + 闭合端合不到位"，说明可用窗口整体偏低 → 行程整体**向下平移 13.5°**：
> 原 500~1500µs（0~90°）→ 现 **350~1350µs**。
> 宏在 `USER/servo.h`：`SERVO_GRIP_ANGLE_SHIFT_DEG10 = -135`（**单位 0.1°**，-135 = -13.5°；13.5° = 150µs）。
> - 张开端还顶死：再减（-140 / -145）；闭合端顶死发烫：加回来（-130 / -120 / 0）。
> - 平移后的脉宽：全闭 350 / 一键合上(机构30°) 683 / 半开 850 / 全开 1350 µs。

**机械爪有两种控制策略，用 SELECT 键切换**（`g_servo_grip_mode` 可 Watch，0/1）：

| 模式 | 值 | □（张开） | ○（合上） | 行程 |
|---|---|---|---|---|
| **一键张合**（默认） | 1 | 按一次自动走到 90°（完全张开）= 1350µs | 按一次自动走到 30°（机构角）= 683µs | **60°** |
| **点动保持** | 0 | **按住**才向张开方向走，松开停 | **按住**才向闭合方向走，松开停 | 0~90° 全程 |

> - 一键式：**上电**默认停在完全张开（90°，1350µs）；**切换模式时不会立刻动作**
>   （机械爪保持当前位置不动，只有按下 □ / ○ 才一次走到对应端点——避免按 SELECT 时爪子自己跑）。
>   合上端点是机构 30°（683µs），所以实际张合幅度是 **60°**（不是全行程 90°）。
> - 点动模式：移植的是两个关节舵机（MG995/SG90）的那套策略——按住走、松手停，可在 0~90° 内任意位置停留。
> - SELECT 是**边沿触发 + 250ms 去抖**，按住不会连续切换。
> - 模式只在 RAM 里，**重新上电回到默认的一键模式**；想改默认值改 `servo.h` 的 `SERVO_GRIP_MODE_DEFAULT`。

> 机械爪两端都是**机械死点**：0°（全闭）和 90°（全开）都会顶住，**不要长时间停在两端**（会堵转发烫）。
> 夹持物体时舵机本来就处于近堵转状态，若夹住要长时间保持，建议把 `SERVO_GRIP_RELEASE_MS` 设为 1500
> （到位后持续按住超时自动断 PWM 失力），或机械上做自锁/摩擦保持。
> 角度接口：`Servo_SetAngle(2, 0/30/45/60/90)`。

**舵机行程校准（换舵机、改机构或出现卡住/发烫时做）**

> MG90S 是 180° **位置**舵机：500us=0°、1500us=90°、2500us=180°（见 `MG90S 舵机.md`）。
> **舵机自身能转 0~180°，不代表你的机构能用满**——机械爪机构只允许 90°。指令超出机构可用范围 = 顶在死点上持续堵转 = **卡住 + 嗡嗡响 + 发烫**。

1. `USER/servo.h` 里把 `SERVO_CALIBRATE_CH` 设为 `3`（机械爪通道）→ 烧录：该通道从 MIN 起**每 2 秒跳 50µs**，到 MAX 再折返；
2. 盯住它**从哪个脉宽开始卡住/发出堵转声** → 记下这两个值；
3. 把安全值（两端各留 20~50µs 余量）填回 `SERVO2_MIN_US` / `SERVO2_MAX_US`，`SERVO_CALIBRATE_CH` 改回 `0` 并重烧；

5. **再接上连杆**复测（区分"舵机问题"和"机构干涉"）。若脱开连杆正常、接上就卡 → 是机构死点/干涉，要改机械；
6. 如果接上后仍怕长时间堵转，把 `SERVO_GRIP_RELEASE_MS` 设为 `1500`：爪子到位后持续按住超过 1.5s 会**自动断开该通道 PWM 让舵机失力**（松开按键恢复）。

> 还有一种可能：**买到的是 360° 连续旋转版 MG90S**（外形一样、型号只差后缀）。
> 判别法：校准模式下给到某个脉宽后它**一直转不停、不会停在某个角度**，就是连续旋转版 → 无法做位置控制，必须换 180° 款。



> 失联保护已默认放宽到 **10s**：1s 会导致"稳住摇杆就停车、必须不停微动"（已实测遇到）。
> 想更硬的安全，建议用 START 键做使能式急停（还没实现，需要就告诉我）。

## 5b. 高占空比导致系统板复位/打火（实测遇到，必须处理）

现象：高档位大占空比时 MCU 复位、电机接插件打火。**已在固件侧把全局占空比上限压到 92%**（`CTRL_DUTY_CAP`），
但这只是缓解——复位/打火的根因在**电流路径**上，务必按下表逐项排查：

| # | 排查项 | 判据 / 处理 |
|---|---|---|
| 1 | 电机电源与逻辑电源是否分开 | 电机经粗线直供 DRV8833 VM；MCU 走独立 5V 降压。**不要共用细线** |
| 2 | VM 就近大电容 | DRV8833 的 VM-GND 之间 **470~1000µF 电解 + 0.1µF 瓷片**，线越短越好（缺它就是"瞬时掉压 → MCU 复位"） |
| 3 | 电池与线径 | 2S 满电 8.4V、内阻小的电池；电机线 ≥20AWG 并尽量短 |
| 4 | 接插件 | **打火多发生在接插件**：接触电阻大 → 局部发热/拉弧。换 XT30/XT60，压接可靠，别用杜邦线走电机电流 |
| 5 | 共地 | 电池负极、MCU GND、DRV8833 GND、接收器/舵机电源 GND **单点汇聚**（地线环路会引起复位） |
| 6 | 电池电量 | 电压低时同样功率下电流更大，更容易复位；<7.0V 先充电 |
| 7 | 堵转 | 轮子被卡住时电流最大，最容易复位；先架空车体测高档 |
| 8 | DRV8833 温度 | 发烫明显要散热或降低占空比上限 |
| 9 | **电机软启动** | 固件已默认开启（`MOTOR_SLEW_ENABLE=1`，每 10ms 最多变 `MOTOR_SLEW_STEP=60`，约 170ms 爬满）——削启动浪涌、降低 dV/dt 干扰 |

> 判据：如果**架空（空载）跑高档不复位、下地就复位**，基本就是第 1/2/3/4 条的电流路径问题。

### 5b-0. "一动摇杆就复位"—先分清是**掉电**还是**复位脚被干扰**

用开机闪码（`BOOT_RESET_CAUSE_BLINK = 1`）看复位原因，两类原因治法完全不同：

| 闪码 | 复位类型 | 病因 | 主要对策 |
|---|---|---|---|
| **1 闪** | **PINRSTF（NRST 被拉低）** | **电源没掉**，是电机/PWM 的干扰打到了复位脚 | ⭐ NRST 对地并 **100nF 瓷片**（就近）、电机端子并 0.1µF、电机线远离 MCU/NRST 走线、单点共地、软启动 |
| 2 / 4 闪 | PORRSTF（掉电/欠压） | 电源轨真的塌了 | 见上面 5b 表：VM 大电容、线径、接插件、电池 |
| 3 闪 | PIN + SFTRSTF | 调试器/烧录器复位（正常） | — |

> **实测案例（另一辆车）**：STBY 接上 VCC 后一推摇杆就复位，闪码 = **1 闪** → 不是供电问题，是干扰打复位脚；
> 对策：NRST 加 100nF + 电机软启动（`MOTOR_SLEW_ENABLE`）。

### 5b-1. 判断"这次复位到底是什么原因"（`g_reset_cause`）
`main.c` 在启动最开头把 `RCC->CSR` 的复位标志锁存到全局变量 **`g_reset_cause`**，然后清除标志。
因为复位标志**只能软件清除**，不这样做的话第一次上电的 POR 标志会一直留着、后面任何复位都读不出真相。

**读法（CLion）**：Debug-STM32 启动调试 → Debug 窗口 **Variables 面板 → 点 "+" 添加 Watch：`g_reset_cause`**（或用 Evaluate Expression 输入）→ 让复位发生 → **Pause** → 看值。

| 位掩码 | 含义 | 说明 |
|---|---|---|
| **0x08000000** | PORRSTF | **上电/欠压类复位** → 供电确实被中断/塌陷（查电流路径、继电器、接插件） |
| **0x04000000** | PINRSTF | **NRST 复位脚被外部拉低** → 干扰/噪声/复位按键（查 EMI：电机端子电容、NRST 对地 100nF、走线远离） |
| 0x10000000 | SFTRSTF | 软件复位（代码主动复位，本工程不会出现） |
| 0x20000000 | IWDGRSTF | 独立看门狗（本工程未开） |
| 0x0C000000 | POR + PIN | **上电首次**的典型值（正常现象） |

> 判读：运行中复位后读到 **0x08000000** → 供电问题；读到 **0x04000000** → 复位脚被干扰（电源没问题）；
> 读到 **0x0C000000** → 断电式复位（既掉电又过复位脚）；读到 **0x14000000** → **调试器/烧录器发起的复位**（不是故障，是烧录或 attach 时自己造成的）。
> 注意：上电后第一次启动读到 0x0C000000 是**正常**的，要判的是"运行中复位之后那次启动"读到的值。

**⚠️ 调试器会覆盖记录**：一 attach 或烧录，ST-Link 就会复位芯片，把你要观察的那条记录冲掉。
所以要么**用闪码（不接调试器）**，要么先让故障发生、再想办法读取（很难不被覆盖）。

**闪码方式（不接调试器也能看上次复位原因）**：把 `Core/Src/main.c` 的 USER CODE PD 里
`#define BOOT_RESET_CAUSE_BLINK 0` 改成 `1` → 烧录 → 之后每次上电，**慢速 LED(PA8) 会闪码**（闪 3 遍，每遍间隔 1.2s）：

| 闪几次 | 含义 |
|---|---|
| 1 次 | 只有 PINRSTF → **复位脚(NRST)被干扰拉低** → EMI 问题，查电机噪声/NRST 电容/走线 |
| 2 次 | PORRSTF → **上电/欠压类** → 供电被切断/塌陷，查继电器/接插件/VM 电容 |
| 3 次 | PIN + SFTRSTF → **调试器/烧录器的复位**（正常现象，不是故障） |
| 4 次 | POR + PIN → **断电式复位**（既掉电又过复位脚） |
| 5 次 | 其它 |

> 用法：开着继电器跑，推杆把故障复现 → 板子重启后**盯着 PA8 数闪几下** → 测完把宏改回 0。

## 5c. 电源与继电器接线（方案一：MCU 不受继电器影响）★已选定

**问题背景**：24V 线圈继电器在 7.4V 下处于"半吸合"临界状态，电机一动就抬开触点 → 整车瞬间断电 →
MCU 上电复位。实测证据：压降仅 0.119V（排除接触电阻）、触点 0.6mV（排除接触不良）、
闪码 **4 次 = PORRSTF+PINRSTF**（确认是真正的断电式复位，不是干扰、不是死机）。

**接线（最终方案）**

```
2S 电池 (+)
  │
  ├─[保险丝 10A]──┬──────────────► 继电器 COM
  │               │                    │ (NO 触点，吸合=导通)
  │               │                    ▼
  │               │             DRV8833 VM ──► 四路电机
  │               │             舵机 5V 电源 ──► MG995/SG90/MG90S
  │               │
  │               └─[保险丝 1A]──► 降压器 IN ──► 5V ──► MCU + PS2 接收器
  │
2S 电池 (−) ─────────────────────────────────────────► 单点汇聚 GND
                              （电池负/驱动GND/舵机电源GND/降压GND 都汇到这一处）
```

要点：
1. **MCU（降压器）直接从电池取电，不经过继电器** ← 这是方案一的核心，继电器怎么开合都不会让 MCU 复位；
2. 继电器只切**电机 + 舵机**电源 → 远程断电时车动不了，比赛功能仍成立，且 MCU 还活着（灯还亮、能继续观察状态）；
3. **线圈必须换 5V 版本**：24V 线圈在 7.4V 下根本吸合不了 → 若用 NO 接法，电机将永远得不到电，
   远程断电功能也失效。用降压器的 5V 给线圈供电最稳（吸合约 70~90mA）；
4. **用 NO 而不是 NC**：吸合=通电，一旦无线模块失电/失控 → 触点释放 → 自动断电（fail-safe）；
5. **线圈并续流二极管**（模块自带就确认一下；没有就加 1N4007，阴极接线圈 + 端）；
6. 线径与端子：电池→继电器→VM 全程 **≥18AWG、尽量短**，用 **XT30/XT60**，杜邦线禁止走电机电流；
7. **VM 侧电容 470µF 左右即可**（别用 1000µF 以上，否则继电器闭合瞬间的充电浪涌容易烧蚀触点；
   也可以并一个 100Ω/1W 预充电电阻跨在触点两端）；
8. 在 **MCU 的 5V 输入端并 470~1000µF 电解**：万一还有别的瞬时跌落，MCU 能"掉电穿越"几十毫秒。

**改完验证**

| # | 检查 | 期望 |
|---|---|---|
| 1 | 上电（`BOOT_RESET_CAUSE_BLINK` 仍为 1） | 慢速 LED 闪 **3 次**（= 烧录器复位，正常） |
| 2 | 装好继电器，推杆跑 2~3 分钟 | **不再出现闪 4 次** |
| 3 | 无线模块断开/断电 | 电机与舵机断电（车动不了），**MCU 仍在运行**（档位 LED 还亮） |
| 4 | 重新上电 | 一切正常，档位回中速 |

> 测完把 `BOOT_RESET_CAUSE_BLINK` 改回 `0`（`Core/Src/main.c` USER CODE PD）。

## 5d. 独立看门狗（IWDG，1 秒超时）

**作用**：程序卡死/跑飞/强干扰导致控制流异常时，1 秒内自动复位芯片，重新进入"摇杆回中 200ms"的安全启动，
避免小车僵在原地或带着最后的 PWM 冲出去（只能靠人拔电池）。

**参数**（`USER/watchdog.h`，直接在寄存器里配，不依赖 CubeMX）：

| 项 | 值 |
|---|---|
| 时钟 | LSI ≈ 40kHz（独立，不依赖主时钟/PLL） |
| 预分频 | `WATCHDOG_PRESCALER = 4`（/64 → 625Hz） |
| 重装值 | `WATCHDOG_RELOAD = 625` |
| **超时** | 625 ÷ 625 = **标称 1.0 秒**（LSI 实际 30~60kHz → 真实 0.67~1.33s） |
| 喂狗 | 主循环每轮 `Watchdog_Feed()`（10ms 一轮，余量充足） |

**改超时**：`RELOAD = 目标秒数 × 625`。例如 2 秒 → 1250；1.5 秒 → 937。

**两个已处理好的坑**：

1. 初始化里置了 `DBGMCU_CR.DBG_IWDG_STOP` → **调试器暂停内核时 IWDG 冻结**，在线单步/暂停不会被踢复位；
2. 看门狗在**所有初始化之后**才启动（PS2_Init、自检这些长流程不会误触发）。

**注意**：IWDG 一旦启动**软件无法关闭**（只能复位关闭）——这正是安全属性。若要用调试器长时间停在断点上，
把 `USER/watchdog.h` 的 `WATCHDOG_ENABLE` 临时改成 `0` 重烧。

**验证**：正常运行不应出现复位；若运行中偶尔"停一下又恢复"且 `g_reset_cause` 显示
IWDGRSTF（0x20000000）→ 说明主循环被卡住超过 1 秒，去查是不是哪里加了长延时。

> ⚠️ **当前状态：看门狗已临时关闭**（`USER/watchdog.h` 的 `WATCHDOG_ENABLE = 0`，用于排查另一辆车的无 PWM 问题），
> 排查结束后请改回 `1`。

## 5e. 档位 LED 闪码：当前为什么不能驱动（无调试器也能判断）
无法驱动时，**快速档 LED（PA12）每 2 秒按次数闪烁**（一次"闪" = 亮 150ms + 灭 150ms）。
正常可驱动时**不闪**。开关在 `Core/Src/main.c` 的 `LED_DIAG_BLINK`（默认 1，置 0 关闭）。

| PA12 闪几次 | 含义 | 怎么处理 |
|---|---|---|
| **不闪** | 正常，已 armed 可驱动 | — |
| **1 闪** | **未 armed**：四轴没在 108~148 内保持 200ms（摇杆没回中 / 数据被拒） | 摇杆放中位；调试器看 `g_rc_dbg.last[0..3]` 是否接近 0x80 |
| **2 闪** | 手柄**掉出模拟模式**（绿灯/数字模式） | 驱动会自动重发配置拉回；若一直 2 闪 → 手柄电池弱 / ANALOG 键坏 |
| **3 闪** | **失联保护**：手柄数据 **10 秒没变化** | **推一下摇杆就会自动恢复**（防"手柄关机后车继续跑"的设计，不是故障） |
| **4 闪** | **完全读不到手柄**（SPI 通信失败） | 查接收器供电(3.3V)、DAT/CMD/CS/CLK 接线、接收器与手柄是否配对 |

> 上电后**约 0.2 秒的短暂闪烁是正常的**（安全启动 arming 期间），之后应停止；
> 如果超过 10 秒不去动摇杆就会变成"3 闪"（失联保护），**推一下摇杆立刻恢复**。

## 7. 常见现象速查

| 现象 | 先查 |
|---|---|
| 灯变暗 / MCU 复位 | 5V 带载电压、3.3V 脚、电池电量、换板对比 |
| 推摇杆无反应 | `g_ps2_dbg.id`；`0x73` 才有摇杆数据；不再涨则查接线/供电 |
| 手柄突然不响应、按 ANALOG 才恢复 | 已自动修复：看 `mode_recover_count` 是否在涨；没涨说明未被识别为掉模式（查 `g_ps2_dbg.id`） |
| 前进变成打转 | 麦轮 `vx` 系数（应四轮同号） |
| 某个轮子反向 | `MOTOR_SIGN_xx` |
| 绕后轮时不是"一个轮子不动" | 量底盘尺寸填 `CTRL_HALF_LEN_MM`/`CTRL_HALF_WID_MM`；或调 `CTRL_PIVOT_OPPOSITE_SIDE`/`CTRL_PIVOT_SIGN` |
| 上电就窜车 | 摇杆是否在中位；`armed` 应先是 0；垃圾数据会解除使能 |
| 手柄关机后车继续跑 | 失联保护：`g_rc_dbg.stale` 是否变 1（超时 10s） |
| 跑着跑着"停一下又恢复"、看门狗复位 | `g_reset_cause == 0x20000000`（IWDGRSTF）→ 主循环被卡 >1s，查长延时；必要时调大 `WATCHDOG_RELOAD` |
| 舵机抖动/复位 | 舵机电源带载不够或没共地；单独 5V + 大电容 |
| 舵机不动 | 量 PA6/PA7/PB0 是否有 50Hz PWM（示波器/逻辑分析仪）；确认 `Servo_Init()` 被调用 |
