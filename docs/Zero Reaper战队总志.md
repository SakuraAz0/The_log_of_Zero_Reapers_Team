## 10.11 — 战队第二次线下会议

**地点**：B区二食堂

**时间**：10：00

**会议内容**：讨论了比赛方案，明确第二阶段的具体工作（具体内容详见 “*10.11会议论点.md*” 文件）

#### **会议产出**：

- ##### 机器人的拾取方案：

  - 提议环节：讨论出**两齿机械臂抓取**、**钩爪勾取**、**长棍挑取**三种方式。其中**机械臂列为首选（最稳定），其次钩爪，长棍（备选)**。

  - 结合实际：考虑到方块的摆放位置和高度不同，采用**两个自由度**的机械臂爪，以实现机械臂的上下转动；结合方块的镂空的结构，**优先采用机械臂方案。**

  - **最终决定**：采用单/双机械臂方案，使用单舵机控制机械臂的高度，抓取方块。（原因：该方案风险最小，稳定性高，且机械臂具有跟多的机动性）

  - 拓展：发现部分方块摆放是成对摆放，因此想出了单车装上双机械臂的想法；该想法的初步实现方案为确认成对方块之间的距离，调节车上双机械臂之间的距离，以达到一次抓取两块方块的目的。

- ##### **方块运输模式：**

  围绕拾取功能进行讨论，考虑到机械臂的转角限制，提出**车头前置倾斜挡板的方式**、**机械臂向后转动放置的方式**完成存放。

  - **车头前置挡板**：在车头前置一块可以转动（或者固定一个倾斜角度）的倾斜挡板；方块被机械臂抓取放置到挡板上，再从挡板上自由滑至储存仓内。

    **优点：**

    1. 机械臂转动角度小；
    2. 耗时短；
    3. 代码控制容易。

    **缺点：**

    1. 无法控制方块滑落位置，易造成**方块堆积堵塞滑道**；
    2. 机械臂可能会与挡板发生空间冲突。

    

  - **机械臂后转放置**：当机械臂完成抓取后，控制机械臂向后转动至储存仓上方，再松开机械臂，让方块自由落入仓中。

    **优点：**

    1. 充分利用了高度空间；
    2. 实现方块的堆积，充分利用储存仓空间。

    **缺点：**

    1. 机械臂转动角度限制；
    2. 转动过程中需要防止物块被机械臂钩住导致无法下落。

    

- ##### **双机器人职能分工：**

  提议阶段：考虑到场地分为高台区域和平地区域，且每个区域都存在方块，我们决定将两辆车的重心分别放在平地区域和高台区域的方块拾取上面，并且加以配合。

  = **每辆机器人的功能：**

  - 单兵作战能力：每辆机器人都能够独立完成方块的拾取和储存；
  - 独自对抗能力：每辆机器人都可以使用车上的拓展部件实现与对手对抗的能力。（如偷取对方方块，阻碍对手行动等等）
  - 己方相互配合作战能力：两辆机器人可以互相配合，使用策略（上下配合）。

  = **特化功能（暂定）**

  - 第一辆（攻击型）：
    1. 实现快速行动，夺取主动权；
    2. 能够主动进攻对手；
    3. 拾取方块、转场的速度更快（重量轻）；
    4. 待优化。

  - 第二辆（防御型）：
    1. 实现防御功能，防范对手意外的攻击（搭载防御外置）；
    2. 底盘更加稳定，重在阻碍对手行为（重量拉满）；
    3. 实现辅助功能；
    4. 待优化。

- ##### **对抗手段（暂定）：**

  考虑到各位队员空闲时间不一致和校区不同，我们采取线上收集信息的方式:

  - **有新想法时：**

  1. 随机队员随机蹦出鬼点子；

  2. 告知队长或者管理（后续提供一个专门的收集渠道）；

  4. 由全体队员审核（想法是否符合实际，对应的功能组能否完成，是否在比赛规定之内，资金消耗等方面进行考虑）；

  之后由全体队员投票表决，少数服从多数。
  通过审核的命题交由对应功能组实现；未通过的驳回想法。

  - **出现问题时：**

  1. 在落实想法的过程中，出现新的问题时。
  2. 先在该功能组内进行评议是否能够解决；
  3. 仍未能解决的，可以尝试咨询学长或者其他队伍；
  4. 实在无法解决的，告知队长，由队长发起全队商议，决定是否废止该想法/功能。
